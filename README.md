# 📚 Read Tracker Bot

Телеграм-бот для отслеживания прочитанных и планируемых к прочтению книг. Использует нейросеть OpenAI для поиска и рекомендаций книг, хранит данные в базе с помощью SQLAlchemy и Alembic, а также поддерживает диалоги через `aiogram-dialog`.

---

## 🛠 Технологии

* **aiogram 3** — фреймворк для создания Telegram-ботов.
* **aiogram-dialog** — управление многошаговыми диалогами с пользователем.
* **SQLAlchemy + Alembic** — работа с базой данных и миграции.
* **Redis** — хранение состояния диалогов и сессий.
* **OpenAI API** — поиск и рекомендации книг через нейросеть.
* **Docker** — контейнеризация и удобное разворачивание проекта.

---

## ⚙️ Настройка

1. Склонируйте репозиторий:

```bash
git clone <REPO_URL>
cd <REPO_NAME>
```

2. Создайте и заполните `.env` на основе `.env.example`:

Не забудьте указать данные для использования GPT
```env
OPENAI_API_KEY=ваш_openai_api_key
MODEL=название_модели
```

---

## 🚀 Запуск

### Через Docker

1. Соберите и запустите контейнеры:

```bash
docker compose up --build -d
```

2. Примените миграции для создания базы данных внутри контейнера:

```bash
docker compose exec bot alembic upgrade head
```
---

## 💡 Использование

### Основные функции:

1. **Добавление книг**

   * Добавляйте книги в список «Прочитанные» или «Планируемые к прочтению».
   * Используется поиск по названию с помощью нейросети.

2. **Отслеживание прогресса**

   * Просматривайте свои прочитанные книги.
   * Отмечайте книги как прочитанные.

### Примеры команд:

* `/start` - начать работу с ботом.
* `/users` - просмотр пользователей и выдача прав (команда для админов)

---

## 🔗 Примечания

* Для корректной работы поиска книг через нейросеть обязательно укажите **OPENAI_API_KEY** и **MODEL** в `.env`.
* Redis используется для хранения состояния диалогов (`aiogram-dialog`).
* Рекомендуется запускать проект через Docker для удобного разворачивания и управления зависимостями.
