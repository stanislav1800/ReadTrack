## 🗂 О проекте

**Read Tracker Bot** — персональный трекер чтения в Telegram. Пользователь ведёт список книг с тремя статусами, ищет книги в общей базе и добавляет новые — вручную или через AI-поиск.

### 💡 Проблема

Большинство людей читают бессистемно: забывают что хотели прочитать, не помнят что уже читали, не могут вспомнить название книги по смутному описанию. Специальные приложения для этого требуют регистрации, установки и переключения контекста. Telegram уже открыт.

### ✅ Решение

Бот позволяет за несколько нажатий добавить книгу в свой список, отметить прогресс и найти нужную книгу даже если помнишь только тему или примерный сюжет — AI подберёт подходящее.

**Ключевые особенности:**
- 📚 **Личный список с тремя статусами** — «Буду читать», «Читаю», «Прочитал». Статус можно менять в любой момент
- 🔍 **Поиск по общей базе** — сначала ищется в существующей базе книг. Нашёл — добавил одной кнопкой
- 🤖 **AI-поиск через OpenAI** — если книга не найдена в базе, можно описать её как угодно: по названию, автору, жанру или просто «книга про апокалипсис с хорошим концом». AI подберёт варианты
- ➕ **Ручное добавление** — если AI тоже не помог, книгу можно добавить в общую базу вручную
- 🏗 **Построен на [aiogram-base-template](https://github.com/stanislav1800/aiogram-base-template)** — регистрация пользователей, роли, middleware и Docker уже готовы. Проект сосредоточен на бизнес-логике, а не на инфраструктуре

### 🎯 Для кого

| Сценарий | Описание |
|---|---|
| Личный трекер | Ведёшь список что читал и что хочешь прочитать |
| Не помнишь название | Описываешь книгу своими словами — AI находит |
| Книжный клуб | Общая база книг, у каждого свой список и статусы |

### 🔬 Что изучалось в проекте

Основная цель — разобраться с интеграцией OpenAI API: как формировать запросы, обрабатывать ответы, выбирать модель и управлять контекстом. Также отработан паттерн повторного использования готовой инфраструктуры из [aiogram-base-template](https://github.com/stanislav1800/aiogram-base-template) вместо написания с нуля.

## ✨ Возможности

### Личный список книг

| Статус | Описание |
|---|---|
| 📖 Буду читать | Книга в очереди |
| 📝 Читаю | Книга в процессе |
| ✅ Прочитал | Книга завершена |

Статус можно менять в любой момент. Список фильтруется по статусу.

### Поиск книг

```
Пользователь вводит запрос
        │
        ▼
  Поиск в базе книг
        │
   ┌────┴────┐
Найдено   Не найдено
   │           │
Добавить    AI-поиск по OpenAI
в список       │
           ┌───┴───┐
        Найдено  Не найдено
           │         │
       Добавить  Добавить вручную
       в список  в общую базу
```

## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone <URL_репозитория>
cd read-tracker-bot

# 2. Настроить окружение
cp .env.example .env
# Заполните .env — особенно OPENAI_API_KEY и TELEGRAM_TOKEN

# 3. Запустить
docker compose up --build -d

# 4. Применить миграции
docker compose exec bot alembic upgrade head
```

## ⚙️ Переменные окружения

| Переменная | Пример | Описание |
|---|---|---|
| `TELEGRAM_TOKEN` | `123456:ABC...` | Токен бота от @BotFather |
| `ADMIN_IDS` | `[123456789]` | Telegram ID администраторов |
| `OPENAI_API_KEY` | `sk-...` | API-ключ OpenAI |
| `MODEL` | `gpt-4o-mini` | Модель OpenAI для поиска |
| `DB_HOST` | `localhost` | Хост PostgreSQL |
| `DB_NAME` | `readtracker` | Имя базы данных |
| `DB_USER` | `postgres` | Пользователь БД |
| `DB_PASSWORD` | `password` | Пароль БД |
| `REDIS_URL` | `redis://localhost:6379` | Подключение к Redis |
